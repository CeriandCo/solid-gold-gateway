# Responsive Three ways to own

## Mobile
- Stack the heading content and comparison link.
- Use the established 40px mobile display-heading size and the site container gutter.
- Stack cards full-width with scaled phone mockups and comfortable spacing.

## Tablet
- Stack the heading content to protect readable line lengths.
- Use an intermediate 64px vertical section rhythm.
- Test a two-column card grid with the third card spanning the row; adjust only if the phone visuals or copy become cramped.

## Verification
- Check 375px, 767px, 768px, 834px, 1023px, and 1024px for overflow, overlap, card dimensions, and readable text.
- Confirm the current desktop layout remains unchanged and the preview build stays clean.

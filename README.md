# SQOOT Gold Vault

Use the supplied SQOOT Pure Style Guide as the single source of truth for colors, typography, spacing, radii, buttons and emotional register.

Use SQOOT-Website-New-01.jpg and IMG_5216.png as the primary website layout and visual-quality references.

Use IMG_5215.png and the checkout assets only as references for component consistency and future app-preview visuals. Do not build checkout, account, KYC or payment functionality on the website.

Preserve the established SQOOT visual language:

- Deep Forest #1A3A2A

- Warm Gold #C9A84C

- Warm White #FAF8F4

- Cream #F5F0E8

- Cormorant Garamond

- DM Sans

- 2px button radius

- 8px card radius

- Editorial physical-gold photography

- Thin outline iconography

Do not reinterpret the brand, introduce a new color palette, add glassmorphism, gradients, neon, crypto visuals, trading aesthetics or pill-shaped financial buttons.

The supplied gifting designs represent the approved visual quality and design language, but gifting is no longer the primary homepage product direction.

Replace the gifting-first product hierarchy with the three latest paths provided by the client:

1. Buy a physical coin and have it delivered home

2. Buy fractional gold

3. Buy physical gold and store it in the vault

Do not modify AURUM.

# C-5 — AURUM notes archive on /learn

Date: 22 Sep 2026. Not published.

## What was built

- `/learn#aurum-archive`: server-rendered archive of every published AURUM post
  (Daily Notes + Weekly Briefs), newest first, tie-broken by `id desc` so the order is
  deterministic. Drafts, scheduled (`published_at` in the future) and archived posts are
  excluded by the shared `visible()` filter in `src/lib/aurum-editorial.server.ts`.
- Each row: type badge, publication date, title, summary, linking to the existing detail
  URLs `/aurum/notes/:slug` and `/aurum/briefs/:slug`. No URLs changed.
- Filters All / Daily Note / Weekly Brief held in component state only — not in the URL or
  hash. Page size 12 with a Load more button (9 published posts, so one page today).
- Empty state: "No published posts of this type yet."
- Reuses the Learn page `.kc-container`, type scale, card border/radius/shadow tokens. No
  new colours or radii.
- `/aurum#daily-note` gained a "Browse all notes →" link to `/learn#aurum-archive`.
- `/aurum/notes/:slug` now falls back to the database Daily Note when the slug is not one of
  the Learn-fed notes, so every archived row resolves.

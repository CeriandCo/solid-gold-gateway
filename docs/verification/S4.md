# S-4 — Admin infinite redirect loop

Date: 2026-09-20. Nothing published. No secret read, written or printed.

## Root cause

`/admin` redirects to `/admin/posts` (`src/routes/admin.index.tsx`), while every admin
child route had a `beforeLoad` that called `getAdminMe()` and redirected back to `/admin`
for a visitor with no session or no role. The two redirects chased each other: blank page,
endless `getAdminMe` server-function calls.

## What changed

| --- | --- |

| `src/routes/admin.posts.new.tsx` | `beforeLoad` removed |
| `src/routes/admin.posts.$postId.tsx` | `beforeLoad` removed |

| `src/routes/admin-route-guards.test.ts` | New regression test |

No redirects remain in admin child routes. The `/admin` layout (`src/routes/admin.tsx`)
still shows the sign-in screen when signed out or de-listed, and only renders `<Outlet/>`
for a signed-in allowlisted editor. Server functions (`requireSupabaseAuth`, `requireAdmin`)
and RLS are unchanged and remain the real authorization boundary.

## Sign-in redirect origin

`requestAdminSignInLink` (`src/lib/admin.functions.ts`) takes the origin from the incoming
request — `new URL(getRequest().url).origin` — and passes `${origin}/admin` as
`emailRedirectTo` to `signInWithOtp`. So the link always returns to whichever host the
person signed in from; no host is hard-coded, and the published domain works the same as
preview.

Origins this produces in practice:

- `https://solid-gold-gateway.lovable.app/admin` (published)
- `https://id-preview--dfb6b88e-1020-4c5e-920c-1659e913f2e8.lovable.app/admin` (preview)
- `https://project--dfb6b88e-1020-4c5e-920c-1659e913f2e8.lovable.app/admin` and its
  `-dev` twin (stable URLs)
- `http://localhost:8080/admin` (local)

Auth redirect allowlisting is managed for this project by Lovable Cloud, which covers the
project's `*.lovable.app` hosts and localhost; the underlying allowlist is not editable or
enumerable from here, so it could not be dumped verbatim. If a custom domain is added
later, that origin must be added to the allowlist before magic links will land on it.

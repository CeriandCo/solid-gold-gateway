## 1. Sync run

Script: `scripts/s5-catalog-sync.ts` (one-off, imports `syncStripeCatalog()` from
`src/lib/commerce/stripe-catalog.server.ts`), run with `bun run scripts/s5-catalog-sync.ts`.

Structured result:

```json
{
  "mode": "test",
  "keyMode": "test",
  "currency": null,
  "mapped": 0,
  "expected": 6,
  "ready": false,
  "productId": null,
  "problems": [{ "code": "no_currency" }]
}
```

**Outcome: refused — `no_currency`.** The sync bailed *before* any Stripe call, because
`commerce_settings.currency` is `NULL`. Lookup keys are derived as
`sqoot_gift_card_<currency>_<amount_cents>`, so without a currency no keys can be built.
No rows were written (all-or-nothing mapping held). A `warning` row was appended to
`commerce_alerts` (`kind = catalog_sync`) by the existing bail path.

All 6 rows of `gift_card_denominations` are `active = true` and still have
`stripe_price_id_test = NULL` and `stripe_price_id_live = NULL` (the sync refused, so it
wrote nothing). Amounts: 5000, 10000, 25000, 50000, 100000, 200000 cents.

**Single fix required:** set `commerce_settings.currency = 'usd'`, then re-run the sync.

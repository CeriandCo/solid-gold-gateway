## 15–17. Redirects
- **Destinations that redirect:** exactly 1, `/aurum`. Over HTTP it returns 307 to `/aurum?range=1Y`, which returns 200. That is one hop, with no loops and no multi-hop chains (`redirectLoops 0`, `multiHopRedirects 0`, `unexpectedRedirects 0`).
- **Counting note:** the analyser counts 111 occurrences for this redirect. Some are same-page `#…` links on `/aurum` itself, which inherit the page's own HTTP chain. A same-page hash click makes no HTTP request, so these are counted for completeness only.
- **Other redirecting paths:** `/aurum/notes` and `/aurum/briefs` also 307 to their default `?page=1`. No link points at them without a page parameter; the archive links already carry `page`.
- **Where the AURUM redirect comes from (P):**
  - Sources: the header and footer `<Link to="/aurum">`.
  - Mechanism: `validateSearch` in `src/routes/aurum.tsx` sets a default of `range: "1Y"` when the parameter is missing. When a page is loaded in full, the server rewrites the URL to match with a 307. When the link is clicked inside the site, the router adds the same default with no HTTP request. The browser check confirmed this: clicking lands on `/aurum?range=1Y`.
  - The parameter sets the price chart's time range, and `range` is also kept in the URL on purpose when the range buttons are used.
  - **Classification: INTENTIONAL, canonical.** Hard-coding `?range=1Y` in the shared links would duplicate the router's default in a second place, so it was left unchanged.
- **Redirect classification for every redirecting occurrence:**
  - INTENTIONAL: 111
  - UNNECESSARY BUT HARMLESS: 0
  - SUSPICIOUS: 0
  - BROKEN: 0

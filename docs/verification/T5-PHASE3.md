## 2. Methodology
- I started from the crawler artifact (1,451 occurrences). I did not build a second inventory.
- For each occurrence I compared the link text, section heading and nearest id with the destination identity. For pages that means title and H1. For fragments it means the heading and opening text of the target section, which I captured with a separate Playwright pass over every fragment target (54 unique fragment targets).
- Where the crawler's context was not enough, I read the source: homepage cards, Vault, gifting, Learn, the AURUM learn section and the editorial panel.
- Each judgement is written as a rule with its evidence. `semantic.ts` stamps those rules onto every occurrence.
- **Not every occurrence was clicked.** I clicked the changed link, and Phase 2 already clicked the header, footer and mobile menu. Everything else was judged from rendered evidence plus source.

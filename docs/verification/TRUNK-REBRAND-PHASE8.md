# TRUNK rebrand phase 8 — QA report

## Scope and result

Browser QA against the current preview on localhost, October 18, 2026. All 21 requested public routes were visited at exactly 1440 × 1800, 768 × 1800 and 375 × 1800 CSS pixels (63 route/width observations). This does not certify the last published version. Nothing published.

**Application changes: none.** Only this report, its raw browser evidence and the roadmap were written. No database writes, no form submissions, no layout/style/font/image/metadata edits.

No broken images after scrolling each rendered image into view and waiting for loading. No old brand detected in rendered photography/screenshots. Contact still visibly displays the existing social handles; these are the explicit retained-social exception from phase 7, not invented replacement handles.

Font confirmation is qualified: body is Geist on every route and the general display token is Newsreader, but not every heading uses Newsreader. Existing AURUM Cormorant and UI Geist exceptions remain; Partner Terms uses the system serif stack. Fonts were deliberately not changed under the request to keep them unchanged.
